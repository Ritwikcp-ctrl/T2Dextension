Keyboard Distance Privacy Policy

Last updated: September 7, 2026

What Keyboard Distance Does

Keyboard Distance measures typing activity and converts the number of typed characters into an estimated distance.

What We Collect

Keyboard Distance stores only the total number of character-producing keyboard events.

What We Do Not Collect

Keyboard Distance does not collect, store, transmit, or sell the actual text you type.

The extension does not intentionally collect passwords, messages, search queries, personal information, or the contents of text fields.

Data Storage

The typing count is stored locally using Chrome extension storage. The data is not transmitted to an external server.

Third Parties

Keyboard Distance does not sell or share typing activity with third parties.

Data Deletion

You can reset the typing counter at any time using the Reset button in the extension.

Contact

For privacy-related questions, contact the developer through the contact information provided on the Chrome Web Store listing.
